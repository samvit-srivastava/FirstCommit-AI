# 📖 Overview

Understanding an unfamiliar codebase is one of the biggest challenges for developers.

FirstCommit AI transforms any GitHub repository into an interactive knowledge graph that helps developers quickly understand architecture, dependencies, components, routes, and relationships without manually exploring hundreds of files.

Whether you're onboarding to a new company, contributing to open source, or reviewing a project, FirstCommit AI dramatically reduces the time required to understand a repository.

# 🧠 Repository Knowledge Engine (RKE)

The Repository Knowledge Engine indexes every repository into a deterministic graph.

Nodes include

- Files
- Components
- Classes
- Functions
- Routes

Relationships include

- Imports
- Calls
- Renders
- Defines
- Exports
- Handles
- Belongs To

This enables intelligent repository exploration without relying on LLM reasoning.

# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/YOUR_USERNAME/FirstCommit-AI.git
cd FirstCommit-AI
```

---

## Frontend

```bash
npm install

npm run dev
```

---

## Backend

```bash
cd backend

python -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

---

Open

```
http://localhost:3000
```
